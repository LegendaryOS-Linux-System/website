LEGENDARYOS

Nowoczesna, niezmutowalna dystrybucja Linux oparta na Fedorze. Zaprojektowana dla bezpieczeństwa, odporności i pełnej kontroli nad systemem.

KLUCZOWE FUNKCJE

⬣

IMMUTABLE ROOT FILESYSTEM

Partycja systemowa jest zamontowana tylko do odczytu. Żadna aplikacja ani użytkownik nie może przypadkowo uszkodzić rdzenia systemu. Twoja instalacja zawsze pozostaje czysta.

read-only /

OCI CONTAINER IMAGES

Cały system operacyjny jest dystrybuowany jako obraz OCI — ten sam format co kontenery Docker i Podman. Wersjonowanie, rollback i audyt stają się trywialne.

oci compliant

ATOMIC UPDATES

Aktualizacje systemu są atomowe — albo aplikowane w całości, albo wcale. Nigdy nie zostaniesz z napół zaktualizowanym systemem po utracie zasilania. Do aktualizacji używasz bootc upgrade.

zero partial updates

BŁYSKAWICZNY ROLLBACK

Coś poszło nie tak? Jedno polecenie lub restart z poprzedniego wpisu w bootloaderze przywraca dokładnie poprzedni stan systemu — bez utraty danych w /home.

instant recovery

RPM-OSTREE & DODATKOWE PAKIETY

Jeśli chcesz doinstalować pakiet bezpośrednio do systemu bez budowania własnego obrazu, użyj rpm-ostree install. Zmiana zostanie zastosowana przy następnym restarcie i można ją cofnąć.

rpm-ostree overlay

TOOLBOX / DISTROBOX

Środowiska deweloperskie działają w izolowanych kontenerach przez Toolbox lub Distrobox. Instaluj dowolne narzędzia bez dotykania systemu hosta.

Przełącz istniejący system oparty na Fedorze bezpośrednio na LegendaryOS — bez reinstalacji, bez utraty danych.

# Upewnij się, że bootc jest zainstalowany
sudo dnf install bootc

# Przełącz na LegendaryOS
sudo bootc switch ghcr.io/legendaryos-linux-system/legendaryos:0.0.1

# Sprawdź status
bootc status

# Zrestartuj, aby zastosować zmianę
systemctl reboot
Dane w /home i /var pozostają nienaruszone. Konfiguracje w /etc są scalane automatycznie przez mechanizm 3-way merge.

Zbuduj własną wersję LegendaryOS jako obraz OCI. Dodaj pakiety, konfigurację, usługi systemd — wszystko deklaratywnie w jednym Containerfile.

# Containerfile — własny obraz oparty na LegendaryOS
FROM ghcr.io/legendaryos-linux-system/legendaryos:0.0.1

# Dodaj pakiety przez dnf
RUN dnf install -y vim git htop && dnf clean all

# Skopiuj własną konfigurację
COPY my-config/ /etc/

# Zbuduj i wypchnij do rejestru
podman build -t ghcr.io/moj-user/moj-legendary:latest .
podman push ghcr.io/moj-user/moj-legendary:latest

# Przełącz system na własny obraz
sudo bootc switch ghcr.io/moj-user/moj-legendary:latest

CZYM JEST IMMUTABLE LINUX?

⬣

Tradycyjne dystrybucje Linux pozwalają na modyfikację każdego pliku systemowego. LegendaryOS stosuje odmienną filozofię — system jest prawdą, a zmiany są wyjątkiem, nie regułą.

ODPORNOŚĆ NA USZKODZENIA

Przypadkowe rm -rf, błędna konfiguracja, wadliwy skrypt — żadna z tych operacji nie może dotknąć partycji systemowej zamontowanej tylko do odczytu.

PEŁNA PRZEWIDYWALNOŚĆ

Stan systemu po uruchomieniu jest zawsze identyczny z obrazem OCI. Zero "działa u mnie" — każda instalacja tego samego obrazu jest bit-for-bit identyczna.

BEZPIECZNE AKTUALIZACJE

Aktualizacje wykonujesz poleceniem bootc upgrade. Są testowane i podpisane przed wydaniem. Jeśli coś pójdzie nie tak — reboot przywraca poprzednią generację.

DANE W /home SĄ BEZPIECZNE

Pliki użytkownika w /home oraz /var nigdy nie są dotykane przez aktualizacje systemu. Twoje dane i konfiguracje pozostają nienaruszone.

MNIEJSZA POWIERZCHNIA ATAKU

Złośliwe oprogramowanie nie może modyfikować plików systemowych nawet po uzyskaniu uprawnień użytkownika. System hosta pozostaje czysty.

SZYBSZE STARTY

System nie musi weryfikować spójności tysięcy plików przy każdym rozruchu. Obraz jest zaufany i niezmienny — boot jest szybszy i pewniejszy.

FAQ

Jeśli chcesz doinstalować pakiet RPM bezpośrednio do systemu, użyj rpm-ostree install <pakiet> — zmiana zostanie zastosowana po restarcie i można ją cofnąć. Aktualizacje systemu wykonujesz poleceniem sudo bootc upgrade. bootc pobiera nowy obraz OCI i aplikuje go przy następnym restarcie. Jeśli coś pójdzie nie tak, możesz natychmiast wrócić do poprzedniej wersji przez sudo bootc rollback lub wybierając poprzedni wpis w GRUB.
bootc i rpm-ostree to dwa różne narzędzia, które współistnieją w LegendaryOS. bootc służy do przełączania i aktualizowania całego systemu przez obrazy OCI — to on odpowiada za atomowe aktualizacje i rollback. rpm-ostree z kolei pozwala na "nakładanie" dodatkowych pakietów RPM na istniejący obraz bez potrzeby budowania własnego — przydatne gdy chcesz doinstalować coś szybko. Oba narzędzia działają na tej samej warstwie ostree.
LegendaryOS synchronizuje się z cyklem wydań Fedory. Wydania pojawiają się regularnie wraz z nowymi wersjami Fedory. Automatyczne sprawdzanie aktualizacji można skonfigurować przez timer systemd.
Katalog /etc jest nadpisywalny i zarządzany przez mechanizm 3-way merge. Twoje lokalne zmiany są zachowywane podczas aktualizacji i scalane ze zmianami z obrazu. /var i /home są w pełni pod kontrolą użytkownika i nigdy nie są nadpisywane przez aktualizacje.
Tak. LegendaryOS obsługuje Secure Boot przez podpisane obrazy jądra i bootloadera. Obrazy OCI są podpisywane kluczem projektu i weryfikowane podczas aktualizacji. Możesz też dodać własne klucze MOK.
Rollback jest błyskawiczny: uruchom sudo bootc rollback i zrestartuj, lub wybierz poprzednią pozycję w menu GRUB. System powróci do dokładnego stanu poprzedniej generacji bez dotykania danych użytkownika.
Distrobox i Toolbox pozwalają na uruchamianie pełnoprawnych kontenerów Linuxa z poziomu terminala. Przykład: distrobox create --name dev --image ubuntu:24.04 tworzy kontener Ubuntu, a distrobox enter dev do niego wchodzi. W kontenerze możesz instalować cokolwiek apt/dnf/pacman bez wpływu na system hosta. Toolbox działa analogicznie i jest domyślnie dostępny po instalacji.
Utwórz Containerfile bazujący na ghcr.io/legendaryos-linux-system/legendaryos:0.0.1, dodaj pakiety przez RUN dnf install -y ..., skopiuj konfiguracje, zbuduj przez podman build i wypchnij do rejestru. Następnie przełącz system na swój obraz przez sudo bootc switch ghcr.io/twoj-user/twoj-obraz:latest. Szczegóły w zakładce "Własny obraz" w sekcji Pobierz.
Aktualnie LegendaryOS obsługuje architekturę x86_64. Minimalne wymagania to ok. 4 GB RAM i 20 GB miejsca na dysku. Wsparcie dla ARM jest planowane w przyszłych wersjach.
